### Root cause ###
In apps/core/management/commands/seed_data.py, the PRODUCTS list has 18
entries, but only 8 of them point at a real per-product image file. The
other 10 all use the exact same fallback:

    'img':'/static/images/products_all.png'

That's why the catalogue looks "repeated" — MD Ametryn, Weed IT 75.7 XL,
Top Fenos 50EC, MD Thion 350EC, MD Thoate 40EC, Toplaxly 72WP, Copper
Oxychloride 850WP, Urea 46%N, NPK 17:17:17, and Foliar Boost all render
the exact same generic group photo.

### Fix ###
Give every product its own unique filename slot (even before you have the
real photo, this stops the visual "duplicate" problem — a broken-image
icon reads better than 10 identical thumbnails, and once you drop in the
real photo with the matching filename it just works, no further code
changes needed).

Replace the 'img' value for these 10 products in PRODUCTS:

    MD AMETRYN 500SC          → '/static/images/product_ametryn.png'
    WEED IT 75.7 XL           → '/static/images/product_weedit.png'
    TOP FENOS 50EC            → '/static/images/product_topfenos.png'
    MD THION 350EC            → '/static/images/product_thion.png'
    MD THOATE 40EC            → '/static/images/product_thoate.png'
    TOPLAXLY 72WP             → '/static/images/product_toplaxly.png'
    COPPER OXYCHLORIDE 850WP  → '/static/images/product_copperoxy.png'
    UREA 46%N                 → '/static/images/product_urea.png'
    NPK 17:17:17              → '/static/images/product_npk.png'
    FOLIAR BOOST 20-20-20+TE  → '/static/images/product_foliarboost.png'

Then run:
    python manage.py seed_data --force

(--force re-seeds so the new image paths take effect on existing rows —
otherwise get_or_create() will leave already-created products untouched.)

### On the blur ###
Blurriness is a source-file problem, not a code problem — the current
images are being upscaled from a smaller original. Two things fix it
going forward:
1. Source photos should be at least 800×800px before upload (the display
   is at 40–220px depending on where it's used, but retina screens render
   at 2x, so anything under ~700px will look soft).
2. The admin "Edit Product" modal shipped in this same update lets you
   re-upload a sharper image for any existing product directly — no need
   to touch seed_data.py again once you have real photography; just edit
   the product and drop the new file in.

Until real photography is available for a given product, it's genuinely
better to leave display_image falling back to '/static/images/products_all.png'
for that ONE product only, rather than having ten products silently share it —
that's what makes the catalogue look mass-produced rather than "we don't
have this photo yet."

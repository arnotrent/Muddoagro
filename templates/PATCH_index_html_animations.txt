### PATCH — homepage product-category animation ###

main.js already has an IntersectionObserver that reveals any element with
a `data-reveal` attribute (fade + slide up) — it just was never applied to
the category cards or product cards on index.html, so they popped in with
no animation. Two small changes:


1) In templates/index.html, find the category loop:

    {% for icon,color,bg,title,url_name,img in categories %}
    <a href="{% url url_name %}" class="cat-card">

   Change to (adds staggered reveal + a data index for the delay):

    {% for icon,color,bg,title,url_name,img in categories %}
    <a href="{% url url_name %}" class="cat-card" data-reveal="scale" data-reveal-delay="{{ forloop.counter0|add:'0' }}00">


2) Do the same for the featured products loop:

    {% for p in featured %}
    <div class="product-card" data-id="{{ p.id }}" ...>

   Change the opening tag to also include:

    <div class="product-card" data-reveal data-reveal-delay="{{ forloop.counter0|add:'0' }}00" data-id="{{ p.id }}" ...>

   (forloop.counter0|add:'0' followed by '00' gives 0,100,200,300... ms
   stagger per card — Django template math is limited, so this string
   trick is the simplest way to get an incrementing delay without a
   custom template filter. If you'd rather have a real filter, add this
   to muddo_filters.py:

       @register.filter
       def mul(v,a):
           try: return int(v)*int(a)
           except: return 0

   already exists in your project — so you can instead write
   `data-reveal-delay="{{ forloop.counter0|mul:80 }}"` for an 80ms step.)


3) Add this small CSS block to animations.css for a nicer hover/press feel
   on category icons specifically (separate from the generic .hover-lift):

    .cat-card{transition:transform .35s cubic-bezier(.34,1.56,.64,1),
               box-shadow .35s ease, border-color .3s ease}
    .cat-card:hover{transform:translateY(-8px) scale(1.015)}
    .cat-card .cat-body > div:first-child{
      transition:transform .3s cubic-bezier(.34,1.56,.64,1), background .3s ease;
    }
    .cat-card:hover .cat-body > div:first-child{transform:rotate(-8deg) scale(1.12)}
    .product-card-img img{transition:transform .5s cubic-bezier(.22,1,.36,1)}
    .quick-view-btn{transition:opacity .3s ease, transform .3s cubic-bezier(.34,1.56,.64,1)}


4) Optional but recommended: the hero stat numbers (Products / Outlets /
   Regions) currently just render as static text. main.js already has a
   `.count-up` counter animation ready to go — add `class="count-up"
   data-target="{{ total }}"` to the `<div class="hstat-num">` spans in
   the hero so they animate from 0 up when scrolled into view.
